# Rainy days

The project is an e commerce store where they sell jackets, you can browse products
add products to cart, checkout and get verification. The products are fetched from data from an API.

## live demo


## Features

- Downloadable CV and cover letter
- single page application
- contact, about me and project pages

## Prerequisites

- Node.js (v20+)
- npm

## Getting Started

- Install Live Server extension
- Click “Go live” and it will open automatically

### Installation

```bash
npm install
```

### Running the project

```bash
npm run dev
```

### Running tests

```bash
npm run test
```

## Environment Variables

Create a `.env` file in the root directory:

```bash
API_KEY=your-api-key-here
BASE_URL=https://example.com/api
```

## Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run test` - Run tests
- `npm run lint` - Run ESLint
